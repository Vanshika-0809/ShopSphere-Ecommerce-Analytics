# ShopSphere-Ecommerce-Analytics
E-commerce Analytics project using SQL, Excel and Power BI to analyze sales, customers, payments, returns and profitability.

## 📌 Project Overview

ShopSphere is an end-to-end E-commerce Analytics project built to analyze sales, customers, payments, orders, profitability, and returns.

The project combines SQL, Excel/CSV data preparation, and Power BI to transform raw e-commerce data into meaningful business insights and interactive dashboards.

## 🎯 Business Objectives

- Analyze overall sales and profitability
- Understand customer purchasing behavior
- Analyze payment methods and payment status
- Compare revenue across states
- Analyze customer segments
- Identify major return reasons
- Build an interactive Power BI dashboard for business reporting

## 🛠️ Tools & Technologies

- SQL / MySQL
- Excel / CSV
- Power BI

## 💳 Payment Analysis

UPI was the highest revenue-generating payment method.

- UPI: 21,511 orders — ₹1.077B revenue
- Credit Card: 13,318 orders — ₹664.51M revenue
- Debit Card: 10,240 orders
- Net Banking: 5,940 orders
- COD: 4,743 orders
- Wallet: 4,248 orders

## 👥 Customer Analysis

The project analyzes customers based on purchasing behavior and customer segments, including:

- Regular
- Premium
- New
- VIP

Returning customers contributed the majority of overall business revenue.

## 🌎 Regional Analysis

The analysis compares revenue performance across different states.

- Maharashtra — ₹535.9M revenue
- Uttar Pradesh — ₹527.2M revenue

## 🔄 Returns Analysis

Top return reasons identified were:

1. Damaged — 1,294 returns
2. Size Issue — 1,238 returns
3. Wrong Item — 1,091 returns

## 🔍 Key Insights

- The business generated approximately ₹2.99B in revenue.
- Overall profit margin was 20.32%.
- UPI generated the highest revenue among payment methods.
- Returning customers contributed significantly to overall revenue.
- Maharashtra and Uttar Pradesh were among the strongest revenue-generating states.
- Damaged products were the most common return reason.
